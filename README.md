# LLM-Controlled Pick-and-Place Robot

An agentic AI system in which an LLM (Gemini API, through function calling) interprets natural-language commands and converts them into physical pick-and-place actions on a Dobot Magician Lite robotic arm.

Solo graduate project, Arizona State University, Fall 2025.

**Tools:** Python, Gemini API (function calling), OpenCV, Dobot Magician Lite
